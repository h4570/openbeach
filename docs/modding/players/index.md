# Modding: players

For players who install and run mods. Pages here are written for someone with a working game and no programming background.
This directory will also hold the catalog of installed mods, the messages of the start-up check and the conflicts between
mods, as those features arrive.

| Topic | What it covers |
|---|---|
| [mods-screen.md](mods-screen.md) | The **Mods** screen in the main menu: switching mods on and off, load order, settings, conflicts and error messages. |
| [switching-mods.md](switching-mods.md) | Turning mods on and off through `[Mods] Active` in `openbeach.ini`, the order that decides which mod wins, and how to switch off a mod that stops the game at start-up. |
