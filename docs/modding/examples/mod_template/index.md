# Text mod template

Copy this directory to `mods/mod_template/` in an L0 game directory and switch it on. Edit the English title in
[text/en.patch.json](text/index.md). When renaming the mod, change both the directory and the `id` in [mod.json](mod.json).

The [first mod guide](../../guides/first-mod.md) explains how to check and run the template.
